
# Temporal Cycle‑Consistency Learning — Midterm Assignment

This repository contains my work for the Temporal Cycle‑Consistency (TCC) learning assignment using the Aegean‑AI TCC notebook and the *multiview‑pouring* dataset.

---

## 📌 Project Overview

Temporal Cycle‑Consistency (TCC) is a self‑supervised method for learning frame embeddings that capture the temporal structure of actions in videos. The embeddings enable tasks such as alignment of video phases, visualization of temporal progression, and unsupervised segmentation.

The notebook provided explores the TCC pipeline, including dataset download, model configuration, attempted training, and analysis.
